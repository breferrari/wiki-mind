# Sources

One note per paper or article you have read. A source note records what the work says, not what you think of the field.

- **Template:** `templates/Source.md`
- **Frontmatter:** `date`, `description`, `tags`, plus `authors`, `year` and `url`
- **Links:** to every concept and entity the source informs. Those notes link back here.

`/wiki-ingest` writes these notes from a URL or a file in `inbox/`.
