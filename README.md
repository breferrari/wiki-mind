# wiki-mind

An Obsidian research vault on the LLM-wiki pattern: you bring sources, an agent reads them and keeps a linked wiki of concepts, entities and comparisons up to date.

wiki-mind is a [ShardMind](https://github.com/breferrari/shardmind) shard.

> **Status:** under construction. The vault itself has not landed yet.

## Install

```sh
shardmind install github:breferrari/wiki-mind
```

Installing through ShardMind lets `shardmind update` merge new releases into your vault without overwriting your edits. A plain `git clone` gives the same vault, without updates.

Windows, macOS and Linux are supported.
