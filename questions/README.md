# Questions

The intake queue: questions and leads to pursue.

- **Template:** `templates/Question.md`
- **Frontmatter:** `date`, `description`, `tags`, plus `status`, which is `open`, `answered` or `dropped`
- **Links:** to whatever raised the question, when anything did.

An answered or dropped question stays here with its status changed. `/wiki-question` files new ones, and `/wiki-ingest` marks the ones a source answers.
