# Syntheses

Comparisons: "X vs Y" notes that sit above concepts and entities. A synthesis says how two or more notes relate, where they agree, and where they don't.

- **Template:** `templates/Synthesis.md`
- **Frontmatter:** `date`, `description`, `tags`, plus `sides`, the two or more notes compared
- **Links:** to each side, and to the sources behind each claim.

`/wiki-synthesize` writes these notes, and refuses when a side has no note yet.
